# Sardinia Skipper ⛵

An arcade boat game on the wild coast of Sardinia. Race through the Mistral storm, rescue tourists and build your fleet.

## ▶️ [Play now in your browser](https://circaalpha.github.io/play/)

**https://circaalpha.github.io/play/**

Works on phone and computer. The web version asks for a tester code the first time. On a phone, add it to your home screen to play full-screen.
